# 개인정보처리방침 초안

과금계산기는 로그인 없이 사용하며 개발자 서버로 개인정보나 계산 내용을 전송하지 않습니다. 광고·분석·결제 SDK를 포함하지 않고 인터넷 권한을 요청하지 않습니다.

계산 입력과 최근 최대 50개 기록은 기기의 앱 전용 저장소에 저장됩니다. 기록 화면에서 개별 또는 전체 기록을 삭제할 수 있습니다. Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 저장 데이터가 삭제됩니다. 앱 기록과 가격은 Android 클라우드 백업 및 기기 전송 대상에서 제외합니다.

출시 전에 운영자명, 문의 이메일, 시행일을 실제 정보로 입력하고 공개 URL에 게시해야 합니다. 현재 문서는 배포 전 초안입니다.
