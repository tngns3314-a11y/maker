# 교대근무

Android 8.0(API 26) 이상에서 사용할 수 있는 네이티브 안드로이드 앱입니다.
설치 파일: `dist/shift-work.apk` (테스트 서명).

## 사용하기

1. APK를 휴대폰으로 옮겨 설치합니다. 필요한 경우 APK를 여는 앱에 대해 이 출처의 앱 설치를 허용합니다.
2. 시작 화면에서 1초 뒤 월간 달력이 자동으로 열립니다.
3. 왼쪽 위 작은 메뉴 → **패턴 입력하기**에서 시작일과 3~10일 반복 주기를 선택합니다.
4. 각 일차의 **주 / 야 / 비 / 휴**와 내용을 입력하고 저장합니다. 내용은 일차마다 100자까지 입력할 수 있습니다.
5. 시작일부터 패턴이 계속 반복됩니다. 시작일 이전에는 근무를 표시하지 않습니다. 날짜를 누르면 그날의 근무와 내용을 수정할 수 있습니다. 수정은 해당 날짜에만 적용됩니다.
6. 달력 아래 **홈 화면 위젯 추가**를 누르거나, 홈 화면의 빈 곳을 길게 눌러 **위젯 → 교대근무**를 선택합니다.

## 표시 띠와 달력 간격 조정 (1.11)

- 위젯 일정·공휴일 네모를 날짜 바로 아래로 이동하고, 표시 띠의 너비와 높이를 채우도록 확대했습니다. 하나만 있으면 전체 너비를, 둘 다 있으면 절반씩 사용합니다.
- 요일 줄 높이를 12dp에서 20dp로 늘리고 글꼴 여백과 자동 크기를 조정했습니다. 같은 위젯 높이에서 날짜 행 간격은 조금 줄어듭니다.
- 앱 달력 행 높이를 116dp에서 96dp로 줄이고 근무 원과 여백을 함께 줄였습니다. 공휴일 이름과 날짜 수정 화면의 전체 정보는 유지합니다.

## 다크 위젯과 달력 가독성 개선 (1.10)

- 모든 위젯을 다크모드로 고정하고 테마 선택 메뉴를 제거했습니다. 기존 화이트/시스템 설정은 더 이상 적용되지 않습니다.
- 오늘·내일의 날짜와 요일 글씨 최대 크기를 25sp에서 18sp로 줄였습니다.
- 달력 위젯에 주 단위 가로 구분선을 추가하고, 날짜 아래에 작은 근무 원을 배치했습니다.
- 일정의 파란 네모와 공휴일의 빨간 네모, 월 이동 및 날짜 누르기는 유지합니다.
- 앱 월간 달력에 공휴일 이름을 표시하며, 날짜를 누른 ‘하루 근무 수정’ 화면에서도 전체 공휴일 이름을 볼 수 있습니다.
- 기존 앱을 삭제하지 않고 1.10 APK를 설치하면 저장된 근무·내용을 유지합니다.

## 달력 위젯 · 요일 · 테마 · 공휴일 (1.9)

- 기존 가로·세로 위젯 날짜를 `10.23 (금)`처럼 표시합니다.
- 새 **달력 4×2** 위젯에 월간 근무를 원형 주/야/비/휴 배지로 표시합니다. 낮은 높이에서도 보이도록 날짜 옆에 배지를 배치합니다.
- 등록한 내용이 있는 날에는 **파란 네모**만 표시합니다. 내용 원문은 위젯과 접근성 설명에 노출하지 않습니다. 날짜를 누르면 앱에서 확인할 수 있습니다.
- 공휴일은 **빨간 네모**로 표시합니다. 일정과 겹치면 두 네모가 함께 표시됩니다. 앱 달력에도 빨간 표시를 추가하며, 선택한 날짜의 상세 영역에서 공휴일 이름을 확인할 수 있습니다.
- 이전/다음 월 이동과 오늘 복귀를 지원합니다. 처음 추가하거나 오늘을 누른 위젯은 현재 월을 자동으로 따라갑니다.
- 앱 상단 메뉴 → **위젯 테마**에서 시스템 설정 / 화이트 / 다크를 선택합니다. 모든 위젯에 함께 적용합니다.
- 추가 방법: **홈 화면 위젯 추가 → 달력 4×2**, 또는 홈 화면의 위젯 목록 → 교대근무 → 달력 4×2.
- 대한민국 공휴일은 2024~2050년의 음력 명절·대체공휴일을 포함합니다. 향후 지정되는 임시공휴일·선거일은 업데이트가 필요합니다. 자세한 기준은 [공휴일 데이터](HOLIDAYS.md)를 참고하세요.
- 기존 앱을 삭제하지 않고 APK를 덮어 설치하면 저장된 패턴과 날짜별 내용이 유지됩니다.

## 위젯 요일 제거 (1.8)

- 가로·세로 위젯에서 오늘과 내일의 요일 표시를 제거했습니다.
- 오늘·내일 제목, 날짜, 근무와 오늘 내용 표시 방식은 유지합니다.

## 시작 화면과 위젯 제목 (1.7)

- 시작 버튼을 제거하고 1초 뒤 달력이 자동으로 열리도록 변경했습니다.
- 시작 그림과 문구를 화면 중앙에 맞춰 배치했습니다.
- 위젯 날짜 위에 오늘·내일 제목을 추가했습니다. 근무 패턴과 내용 표시 방식은 유지합니다.

## 오늘·내일 위젯 (1.6)

- 오늘 내용이 없으면 오늘과 내일의 날짜·요일·근무만 표시합니다.
- 오늘 내용이 있으면 오늘 근무 → 오늘 내용 → 내일 근무 순서로 표시합니다.
- 가로 위젯은 좌우, 세로 위젯은 위아래 순서이며 내일 내용은 표시하지 않습니다.
- 배경과 근무 배지, 위젯을 눌러 오늘 달력 열기 등 기존 동작을 유지합니다.

## 위젯 제목 제거 (1.5)

- 가로 위젯의 작은 ‘오늘의 내용’ 제목을 제거했습니다.
- 내용이 없으면 내용 영역 전체를 빈칸으로 표시하며, 초기 레이아웃의 안내 문구도 제거했습니다.

## 위젯 빈 내용 표시 (1.4)

- 가로/세로 위젯 모두 오늘 입력한 내용이 없으면 내용 영역을 빈칸으로 표시합니다.
- 내용 영역에 미입력 안내, 패턴 등록 안내, 시작일 안내를 대신 표시하지 않습니다.
- 입력한 내용이 있으면 기존과 동일하게 표시합니다.

## 달력 사용성 개선 (1.3)

- 상단의 이전/다음 화살표를 없앴습니다. 달력을 왼쪽으로 밀면 다음 달, 오른쪽으로 밀면 이전 달로 이동합니다.
- 짧게 밀거나 취소한 동작은 월을 바꾸지 않으며, 세로 스크롤과 날짜 눌러 수정하기를 유지합니다.
- 날짜 칸의 입력 내용은 사진처럼 파란 배경과 흰 글씨로 표시합니다. 긴 내용은 날짜를 눌러 전체 확인할 수 있습니다.
- 오늘 버튼과 월 제목을 눌러 날짜 선택하기는 그대로 사용할 수 있습니다.
- 위젯 디자인과 동작은 변경하지 않았습니다. 기존 앱을 삭제하지 않고 업데이트하면 저장된 내용이 유지됩니다.

## 위젯 표시 개선 (1.2)

- 낮은 높이에서도 날짜·동그란 주/야/비/휴 표시·요일을 유지하고 공간에 맞게 크기를 조절합니다.
- 별도의 주간/야간/비번/휴무 글자는 제거했습니다. 입력한 내용 자체는 변경하지 않습니다.
- 기존 앱을 삭제하지 않고 새 APK로 업데이트하세요. 저장된 패턴과 날짜별 수정은 유지됩니다.

## 날짜별 근무 수정 (1.1)

- 달력의 날짜 또는 아래 **선택한 날짜 근무 수정**을 누릅니다.
- 주·야·비·휴와 내용을 바꾸고 **이 날짜만 저장**을 누릅니다.
- 변경한 날짜에만 적용하며 반복 패턴, 다른 날짜, 다음 주기의 같은 일차에는 영향을 주지 않습니다.
- 수정한 날짜는 달력에 **•**로 표시합니다. 오늘의 수정은 두 위젯에도 반영됩니다.
- 수정 화면의 **당일 수정 지우기**로 현재 반복 패턴의 근무와 내용으로 돌아갈 수 있습니다.
- 메뉴에서 반복 패턴을 다시 저장해도 날짜별로 수정한 값은 유지합니다. 패턴 미등록 또는 시작일 이전 날짜에도 하루 단위로 입력할 수 있습니다.

## 오늘과 내일을 표시하는 두 위젯

- **가로 4×1**: 왼쪽에 오늘, 오른쪽에 내일의 날짜·요일·근무를 표시하고 오늘 내용이 있으면 가운데 표시합니다.
- **세로 1×4**: 위쪽에 오늘, 아래쪽에 내일의 날짜·요일·근무를 표시하고 오늘 내용이 있으면 가운데 표시합니다.
- 두 위젯 모두 휴대폰의 오늘 날짜와 같은 저장 패턴을 사용합니다. 입력 내용은 근무 유형 전체가 아니라 해당 일차에 연결됩니다.
- 위젯을 누르면 달력의 오늘 날짜가 열리고 내용 전체를 볼 수 있습니다.
- 위젯을 길게 눌러 크기를 늘릴 수 있습니다. 좁거나 낮은 영역에서는 내용 일부를 줄여 표시합니다.
- 저장 시 즉시 갱신하며 날짜 변경·시간대 변경·재부팅과 주기 갱신도 처리합니다. 절전 상태에서는 운영체제가 갱신을 지연할 수 있습니다.
- 실제 칸 크기와 배치는 휴대폰의 홈 화면 앱에 따라 다릅니다. 4×1/1×4 목표 크기와 이전 버전용 최소 크기를 함께 설정했습니다.

저장 내용은 기기 내부에만 보관하며 인터넷 연결이나 계정이 필요하지 않습니다. 새 패턴을 저장하면 이전 반복 패턴을 대체합니다. 날짜별로 수정한 값은 별도로 보관하며 새 패턴보다 우선 적용합니다.

## 프로젝트와 빌드

- 앱 소스: `shift/src/main/`
- Android Studio에서 프로젝트 폴더를 열고 **shift** 모듈을 실행합니다. 기존 계산기는 별도 **app** 모듈에 남아 있습니다.
- Gradle: `./gradlew :shift:assembleDebug`
- Gradle 다운로드 없이 로컬 SDK로 빌드: `python3 scripts/build-shift.py`
- SDK Platform 36, Build Tools 36.0.0, JDK 17 이상. macOS 기본 경로 외에서는 `ANDROID_HOME`과 `JAVA_HOME`을 지정합니다.
- 날짜 계산 테스트: `shift/tests/ShiftPatternTest.java`
- Android 실행/위젯 호스트 테스트: `shift/androidTest/RuntimeCheck.java`
- 테스트 APK 빌드: `python3 scripts/build-shift-test.py`

테스트에는 3~10일 반복, 윤년·연도 경계, 시작일 이전, 메모 유지, 3일/10일 편집, 저장 후 재진입, 실제 Android 위젯 호스트에서 두 레이아웃 표시 및 저장 즉시 반영을 포함합니다. 삼성 등 실제 휴대폰 런처별 검증은 별도로 필요합니다.

위젯 크기 구현 참고: [Android 공식 위젯 레이아웃 문서](https://developer.android.com/develop/ui/views/appwidgets/layouts).
